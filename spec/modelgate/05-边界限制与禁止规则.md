# Spec Me2AI · 05 · 边界限制与禁止规则

> **文档性质**：人工编写，AI 严格遵守，每条规则均为红线，不得以任何理由绕过
> **同步说明**：本版已与代码对齐（2026-07）：Boot 2.7.18、无 MQ、mapper/domain 包结构、逻辑删除

---

## 1. 功能边界（禁止超范围实现）

| 禁止实现 | 原因 |
|---|---|
| 模型训练、微调、Fine-tuning | 不在本系统职责范围 |
| 用户个人账号体系（登录/注册/密码） | 不是 C 端产品，无用户维度 |
| 跨公司/跨外网访问能力 | 内网网关，不对外暴露 |
| 计费、账单、支付 | v1 不实现，Token 统计仅用于审计 |
| 模型推理能力（直接调用 GPU） | 只做流量转发，不做推理 |
| 多租户/多工作空间 | 单租户内网产品 |
| 前端 SPA 路由（React/Vue） | 管理后台用静态页面（admin.html） |

## 2. 技术选型红线（禁止引入）

### 2.1 ORM 框架禁令

```
禁止引入：JPA / Spring Data JPA / Hibernate / JOOQ / Ebean / 原生 MyBatis（XML Mapper）
必须使用：MyBatis Plus 3.5.9（LambdaQueryWrapper，无 XML）
```

### 2.2 框架版本禁令

```
禁止：
  - 升级 Spring Boot 至 3.x（内网框架/SDK 仅兼容 2.7.18，必须 2.7.18）
  - 降级 JDK 至 8 或 11（必须 JDK 17）
  - 引入 Zuul（必须 Spring Cloud Gateway，Spring Cloud 2021.0.9）
  - 使用/引入 Hystrix（必须 Resilience4j 1.7.0；行内 BaseBizException 已适配去 Hystrix）
  - 引入任何 MQ（Kafka/RabbitMQ/RocketMQ）——审计日志仅写 MySQL，不走消息队列
  - 引入 springfox（swagger 注解统一 io.swagger.v3，springdoc 1.7.0）
```

### 2.3 缓存架构禁令

```
禁止：
  - 只用单层 Redis（必须 Caffeine L1 + Redis L2 双层）
  - 只用单层 Caffeine（Redis L2 用于跨实例同步）
  - Redis 故障时穿透 DB（L1 miss 直接拒绝）
  - 使用 spring-data-redis 直连（必须内网 com.pab.framework:redis CacheProvider）
```

### 2.4 构建工具禁令

```
禁止：切换至 Gradle（必须 Maven）
```

## 3. 包结构禁令

```
禁止：
  - 在 com.pab.ficc.ibp.modelgate.server 下新增顶级子包
  - Filter 类放在 filter/（网关）或 admin/（管理鉴权）以外
  - Mapper 接口放在 mapper/ 以外
  - Entity 放在 domain/entity/ 以外；入参 BO 放在 domain/bo/ 以外；VO 放在 domain/vo/ 以外
  - 在 domain/ 中放业务逻辑（三层对象均为 POJO）
允许：
  - com.pab.ficc.cus.**（行内基础包源码：Result/BizException，后期整体替换为行内 jar，不得自行扩充）
  - com.pab.framework.redis（内网 Redis SDK 适配）
```

## 4. 安全红线

### 4.1 密钥处理禁令

```
禁止：
  - 数据库明文存储上游 API Key / SK（必须 AES-256-GCM 加密）
  - 数据库存储 API Key 原文（必须 SHA-256 hash）
  - 日志打印完整 API Key / SK / 密码（末 4 位可见）
  - 加密密钥硬编码（必须环境变量 MODELGATE_CRYPTO_KEY）
  - HTTP 响应二次返回 API Key 原文（仅创建时一次）
  - 携带默认 Admin Token / Basic 密码上线（上线检查清单见 10 §6）
```

### 4.2 鉴权绕过禁令

```
禁止：
  - 在非 /actuator/health、/actuator/info 路径跳过 AdminAuthFilter
  - 字符串 equals 比对凭证（必须 MessageDigest.isEqual 常量时间）
  - 跳过 AK/SK 时间戳防重放校验（±5min）
  - Filter 内 DB 查询不切 boundedElastic 线程池
```

### 4.3 SQL 安全禁令

```
禁止：
  - 字符串拼接 SQL（必须 MyBatis Plus Lambda API / #{} 参数化）
  - SELECT *（Lambda 查询默认全列映射除外；注解 SQL 必须明确列出字段）
  - 在 Mapper 层以外执行 SQL
```

## 5. WebFlux 线程模型禁令

```
禁止：
  - GlobalFilter 中调用同步 JDBC（必须 Mono.fromCallable + boundedElastic）
  - Filter 中 Thread.sleep()
  - 响应式链中 .block() / .blockFirst() / .blockLast()
  - Netty 事件循环线程中执行任何阻塞 IO
```

---

## 6. Filter 执行顺序保护

```
禁止：
  - 更改任意 Filter 的 order 值（见 02 §3）
  - 在 CredentialAuthFilter 之前增加依赖凭证信息的 Filter
  - 在 ModelRouteFilter 之后增加读取原始请求体的 Filter
  - 跳过 AdminAuthFilter 直接访问 /admin/**
```

---

## 7. 缓存操作禁令

```
禁止：
  - Service 层绕过 GatewayCacheManager 直接操作 Caffeine
  - Controller 层直接操作缓存
  - 写操作后懒失效（必须主动失效缓存）
  - Redis 故障时穿透 DB
```

---

## 8. 业务规则禁令

```
禁止：
  - 删除存在活跃授权的模型（必须先撤销所有授权）
  - 查询接口返回 API Key 原文（只返回末 4 位 + ****）
  - App 禁用时跳过其凭证失效（必须立即失效）
  - 授权过期后自动删除记录（过期仅等同禁用）
  - 访问规则为空时拒绝请求（规则为空 = 不限制来源）
  - 绕过 @TableLogic 直接物理 DELETE 管理表数据（删除必须走逻辑删除；mg_audit_log 清理除外）
```

---

## 9. 接口设计禁令

```
禁止：
  - 更改 /v1/chat/completions 路径（OpenAI SDK 兼容）
  - 更改 /admin/** 已定义接口的 HTTP 方法或路径（值收口在 UrlConstant，改常量=改契约，需评审）
  - Controller 路径使用 @PathVariable（RBAC 按固定路径绑定）
  - Controller 使用路径字面量（必须引用 UrlConstant）
  - 非标准 HTTP 状态码（只用 200/400/401/403/429/500/503/504）
  - Controller 返回裸 T（必须 Mono<Result<T>>，Result 为行内 com.pab.ficc.cus.web.result.Result）
  - 变更网关 Filter 错误响应结构（旧 code/message 结构为对外契约）
```

---

## 10. 代码质量禁令

```
禁止：
  - Entity 使用 JPA 注解（@Entity/@Table/@Column；MyBatis Plus 注解允许）
  - Service 层写 SQL
  - 在 Filter 与 GlobalExceptionHandler 以外向 response 直接写数据
  - System.out.println 打日志
  - Entity 时间字段用 java.util.Date（必须 LocalDateTime）
  - Service 手动 set 基础字段（统一由 AuditFieldMetaObjectHandler 填充）
```
