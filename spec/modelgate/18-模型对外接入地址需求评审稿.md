# ModelGate 模型对外接入地址需求评审稿

状态为首期已实施。范围包括配置、两套管理页的系统与个人模型示例、系统接入示例的模型网关测试。模型管理保留已有上游测试。独立的网关测试入口和个人凭证测试待另行确定。

## 1. 需求与现状

管理员在内网管理 ModelGate，模型调用方通过另一个固定入口访问。管理员配置一次后，两套管理页应使用同一个地址展示模型调用入口、生成可直接复制的请求示例，并以该地址为默认值进行网关全链路测试。

| 位置 | 当前行为 | 拟议行为 |
| --- | --- | --- |
| 网关配置 | 全局开关管理熔断，通用 KV 可新增和维护键值。 | 在同一页面提供「模型对外接入地址」字段，复用现有 KV、配置保存权限和数据库。 |
| 接入系统 → 接入示例 → 模型 | 独立前端用 `VITE_MODELGATE_BASE_URL` 加文根，内置页用当前域名加文根。浏览器按示例地址发起测试。 | 两套页面预填配置地址。展示、复制和测试由同一个最终请求 URL 生成。 |
| 个人接入 → 接入示例 | 按授权模型生成请求，使用前端现有默认地址和个人 Key 占位符。 | 两套页面预填相同配置地址，保留 Key 占位符。 |
| 模型管理 → 连通性测试 / 对话测试 | 后端使用模型配置直连上游，排查上游地址、协议和凭证。 | 保留现有入口和行为。评审是否新增并列的「通过网关测试」入口。 |
| 通用服务 → 接入示例及测试 | 使用现有网关地址和 `/svc/**` 路径。 | 首期维持当前默认地址与逻辑。 |

管理 API 地址、容器监听、探测、SLB 路由、模型上游地址、鉴权、配额和报文录制回放均按现有配置运行。模型对外接入地址只服务于接入展示、请求示例和显式发起的模型网关测试。

## 2. 配置契约

- 建议 Key 为 `gateway.public.base-url`，保存在 `mg_gateway_config`。例如 `https://api.example.com/modelgate`。值是调用方可达的绝对 HTTP(S) 基础地址，包含实际外部路径前缀。外部路径由 SLB 决定，前端直接使用保存值，再拼模型调用路径。
- 保存前去掉首尾空白和末尾斜杠。校验协议、主机和端口。地址中禁止账号密码、查询参数和片段。字段旁给出完整填写示例，避免把具体模型端点填到基础地址里。旧 KV 通用保存入口写同名键时使用相同校验。
- 复用网关配置的查询、保存和删除权限。两套管理页通过受鉴权保护的 `GET /modelgate/config/model-public-base-url` 读取单项地址。响应只包含 `baseUrl`，未配置时为空。通过 user 的 [19 号增量](D:/code/user/user-server/src/main/resources/db/codebuddy-platform/19_modelgate_public_base_url_perm_increment_20261113.sql) 按系统、个人菜单分别授权。
- 未配置、删除后或前端连接尚未提供该接口的旧版本时，回到当前页面的原默认地址。对请求失败或权限拒绝，页面应明确说明未读取到配置，并标明当前显示的是默认地址，便于识别交付地址是否正确。配置变更在重新打开示例时读取，不覆盖用户已手动编辑的输入。
- 管理前端继续从原有管理服务地址请求配置接口。配置地址只用于示例请求和业务测试，不进入全局 HTTP 客户端，也不触发服务端连通性探测。

## 3. 展示、复制与测试

- 系统和个人的模型接入示例统一展示网关基础地址和最终模型接口地址。按当前授权模型及模型类型生成路径、请求头与请求体。配置地址包含文根，拼接时只出现一次。保留现有单次手动改址行为。
- 示例默认保留 API Key 或 AK/SK 占位符，沿用已有复制逻辑。现有按权限显式填入真实系统凭证的流程继续适用。测试使用调用方有效凭证；模型上游密钥仍留在服务端。
- 「接入系统 → 接入示例 → 测试连通」复用当前浏览器测试流程，以页面最终 URL 发起一次请求。网关按原业务链路处理鉴权、来源控制、模型授权、配额和路由。测试结果沿用当前状态、响应和诊断展示。
- 如纳入「模型管理 → 通过网关测试」，建议复用系统接入示例的测试流程并预选当前模型。评审时明确是否允许个人凭证测试、凭证来源与权限。网关测试和现有上游测试分别标示，避免把上游可达误判成调用方入口可达。
- 浏览器跨域测试由目标入口按管理页的来源放行所需方法及请求头。验收要覆盖 CORS、HTTPS 管理页访问 HTTP 目标的混合内容限制和浏览器所在网络能否到达对外入口。浏览器限制应与网关拒绝、上游失败分开提示。保留命令复制能力，供调用方在自己的网络环境运行。

## 4. 评审待确认

| 议题 | 建议口径 |
| --- | --- |
| 配置粒度 | 每套 ModelGate 环境一个默认模型入口。如存在多个出口，先明确哪个用于默认交付。 |
| 入口样例 | 提供实际调用方访问的域名和外部文根样例，确认 SLB 转发规则及不同网络的可达范围。 |
| 模型管理页测试 | 优先复用已存在的系统接入测试入口。若同一期要增加独立入口，确认是否覆盖个人凭证以及谁可发起测试。 |
| 通用服务范围 | 当前需求针对模型。若通用服务的对外地址也与管理地址不同，另行确认它的默认值及读写范围。 |
| 跨域测试 | 确认管理来源、对外入口和允许的请求头。浏览器无法到达时，可复制示例由调用方环境验证。 |

## 5. 验收与发布准备

| 验收项 | 通过条件 |
| --- | --- |
| 配置新增、编辑、删除 | 合法地址正常保存并规范化。非法地址被拒绝，已有值可继续使用。删除后恢复原默认地址。 |
| 独立与内置页面 | 管理地址与调用地址不同的情况下，两套页面的系统和个人模型示例显示相同调用地址，复制结果含正确文根、模型路径和授权模型。 |
| 兼容与权限 | 未配置、接口暂不可用、无读取权限均有明确展示。普通示例权限无法读取其他 KV 或修改配置。 |
| 网关全链路 | 使用测试调用方 Key 向配置地址发送请求。有效授权成功，无权模型或错误 Key 按现有规则拒绝。按用例覆盖流式与非流式，确认配额和审计仍按调用方归属。 |
| 稳定功能回归 | 上游连通性及对话测试仍按模型配置工作。管理 API、通用服务示例、原有接入凭证、路径拼接及报文回放正常。 |
| 上线与回退 | 无数据库结构变更。准备只读接口权限后发布后端，再发布两套管理页。可删除该配置恢复原默认地址，业务路由继续由 SLB 和网关配置决定。 |
