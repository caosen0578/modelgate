# Spec Me2AI · 04 · 接口与数据结构

> **文档性质**：人工编写，AI 严格遵守，接口路径/字段名/类型不得自行更改

---

## 0. 命名规范（与代码强一致）

| 类别 | 后缀 | 包 | 示例 | 说明 |
|---|---|---|---|---|
| 数据库实体 | `Entity` | `domain.entity` | `ModelInstanceEntity` | MyBatis-Plus 实体，`@TableName` 映射表 |
| 前端传值入参 | `RequestBO` | `domain.bo` | `CreateModelRequestBO` | 前端→后端请求体（行内 BO 规范，结尾加 BO） |
| 出参视图 | `VO` | `domain.vo` | `ModelVO` | 后端→前端响应对象 |
| 接口路径常量 | — | `common.UrlConstant` | `UrlConstant.ADMIN_MODELS` | 所有 URL 统一收口，各 Controller 引用，禁止散落字面量 |

**基础字段（内部规范，所有可管理实体强制包含）**：`creater` / `create_time` / `updater` / `update_time` / `is_del`(逻辑删除 `@TableLogic` '0'/'1') / `creater_um` / `updater_um`。由 `AuditFieldMetaObjectHandler` 自动填充，`creater/updater/um` 取自 `OperatorProvider`（当前占位 null，待接入行内用户上下文）。**审计表 `mg_audit_log` 为高频追加表，不含这些基础字段。**

```sql
CREATE TABLE mg_audit_log (
    id             BIGINT       NOT NULL AUTO_INCREMENT PRIMARY KEY,
    trace_id       VARCHAR(64)  NOT NULL,
    app_id         VARCHAR(64),
    model_id       VARCHAR(64),
    cred_type      VARCHAR(32),
    client_ip      VARCHAR(64),
    caller_app_id  VARCHAR(64)           COMMENT '调用方系统标识（X-App-Id Header）',
    request_path   VARCHAR(512),
    http_status    INT,
    latency_ms     INT,
    input_tokens   INT          DEFAULT 0,
    output_tokens  INT          DEFAULT 0,
    error_msg      VARCHAR(1024),
    create_time     DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,

    INDEX idx_app_id (app_id),
    INDEX idx_create_time (create_time)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

> **逻辑删除与唯一键**：启用 `is_del` 逻辑删除后，`deleteById`/`delete(wrapper)` 变为 `UPDATE is_del=1`。软删的行仍占用唯一键，故 `mg_app_model_auth` 唯一键改为 `(app_id, model_id, is_del)`；`mg_model.model_id` / `mg_app.app_id` 等唯一列若需支持"删除后同名重建"，需同步纳入 `is_del`，否则会触发 `Duplicate key`。`mg_gateway_config` 建议物理删除（配置表软删无意义）。

## 2. 管理接口定义（强制，路径和字段名不得更改）

> 所有接口路径统一定义于 `common.UrlConstant`，Controller 通过常量引用（如 `@RequestMapping(UrlConstant.ADMIN_MODELS)`、`@GetMapping(UrlConstant.DETAIL)`）。URL 字符串值与下文一致，未变化。

### 2.1 通用响应结构

管理接口（Controller）统一返回行内标准 `Result`（`com.pab.ficc.cus.web.result.Result`）：

```json
{
  "resultCode": "00000000",
  "resultMessage": "操作成功",
  "data": {},
  "requestId": "abc123def456",
  "requestTime": "2026-04-23 10:00:00.000",
  "logTraceId": "abc123def456"
}
```

- `resultCode="00000000"` 表示成功，其余为业务错误码
- HTTP 状态码与 `resultCode` 分开：HTTP 4xx/5xx 代表协议层错误，`resultCode!="00000000"` 代表业务拒绝
- `requestId`/`logTraceId` 取自 `TraceContext`（WebFlux 下跨 reactor 线程可能为空，属已知限制）
- **注意**：网关对外业务流量（`/v1/**`）由 Filter 直接返回错误，仍使用旧结构（`code`/`message`），与管理接口独立，互不影响

### 2.2 模型管理接口

> **路径设计原则**：所有管理接口路径固定，变量通过 `@RequestParam` 或请求体传递，便于 RBAC 权限表按固定路径绑定角色。请求体对应 `domain.bo` 下的 `*RequestBO` 类。

**GET /admin/models** - 获取模型列表

Response `data`（`ModelVO`）:
```json
[{
  "id": 1,
  "modelId": "gpt-4o",
  "modelName": "GPT-4o",
  "provider": "openai",
  "modelType": "chat",
  "apiSpec": "openai",
  "upstreamUrl": "https://api.openai.com",
  "timeoutMs": 30000,
  "enabled": true,
  "createTime": "2026-04-23 10:00:00.000"
}]
```

**GET /admin/models/detail?modelId={modelId}** - 获取模型详情

**POST /admin/models** - 创建模型（`CreateModelRequestBO`）

Request body:
```json
{
  "modelId": "gpt-4o",
  "modelName": "GPT-4o",
  "provider": "openai",
  "modelType": "chat",
  "apiSpec": "openai",
  "upstreamUrl": "https://api.openai.com",
  "timeoutMs": 30000,
  "defaultParams": {},
  "forceParams": {},
  "description": "OpenAI GPT-4o",
  "credential": {
    "authType": "api_key",
    "secretKey": "sk-xxx"
  }
}
```

**PUT /admin/models/update** - 更新模型（`UpdateModelRequestBO`，body 中含 modelId，不可修改）

**PATCH /admin/models/enable?modelId={modelId}** - 启用模型

**PATCH /admin/models/disable?modelId={modelId}** - 禁用模型

**DELETE /admin/models/delete?modelId={modelId}** - 删除模型（存在活跃授权时返回 400；逻辑删除）

**POST /admin/models/test?modelId={modelId}** - 连通性测试

Response `data`:
```json
{
  "success": true,
  "latencyMs": 342,
  "message": "连通成功"
}
```

### 5.2 枚举值速查

**模型提供商 `provider`**

| 值 | 含义 |
|---|---|
| `openai` | OpenAI |
| `azure_openai` | Azure OpenAI |
| `anthropic` | Anthropic Claude |
| `private` | 私有化部署（OpenAI 兼容） |
| `custom` | 自定义上游 |

**模型类型 `model_type`**

| 值 | 含义 |
|---|---|
| `chat` | 对话补全 |
| `embedding` | 文本嵌入 |
| `image` | 图像生成 |
| `audio` | 语音 |

**API 规范 `api_spec`**

| 值 | 参数转换行为 |
|---|---|
| `openai` | 直接透传，不转换 |
| `azure_openai` | URL / Header 适配 |
| `anthropic` | 请求体 + 响应体全量转换 |
| `custom` | 按 `param_mapping` 字段转换 |

**上游鉴权类型 `auth_type`**

| 值 | 说明 |
|---|---|
| `api_key` | `Authorization: Bearer {key}` |
| `ak_sk` | HMAC 签名 |
| `azure` | `api-key` Header + URL 参数 |
| `none` | 不鉴权（内网私有模型） |

**系统凭证类型 `cred_type`**

| 值 | 说明 |
|---|---|
| `api_key` | 单一密钥，请求头 Bearer |
| `ak_sk` | AK 公开 + SK 签名 |

**访问规则类型 `rule_type`**

| 值 | 示例 | 典型用途 |
|---|---|---|
| `ip` | `192.168.1.100` | 办公区固定 IP 终端 |
| `cidr` | `10.244.0.0/16` | K8s Pod 网段（Pod IP 动态，需用网段） |
| `domain` | `app.internal.com` | 精确域名，匹配请求 `Origin` 头 |
| `domain_wildcard` | `*.internal.com` | 单级通配（`a.b.com` 不匹配 `*.com`） |

> **规则为空 = 不限制来源**，适合纯 K8s 集群内部全信任调用

### 5.3 关键业务级联规则

1. **App 禁用** → 该 App 下所有凭证立即失效（缓存强制刷新）
2. **凭证禁用** → 仅该凭证失效，同系统其他凭证不受影响
3. **模型授权禁用** → 该 App 访问该模型返回 403，其他模型不受影响
4. **模型禁用** → 所有 App 访问该模型返回 503
5. **授权过期** → 过期后等同于禁用，返回 403，记录不自动删除
6. **App 删除** → 级联删除该 App 下所有凭证、授权、访问规则
