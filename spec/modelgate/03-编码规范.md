# Spec Me2AI · 03 · 编码规范

> **文档性质**：人工编写，AI 严格遵守，不得以"代码更整洁"为由绕过规范
> **同步说明**：本版已与代码对齐（2026-07）：Entity/BO/VO 命名、UrlConstant、行内 Result、基础字段自动填充

---

## 1. 命名规范（强制）

### 1.1 类命名

| 类型 | 命名规则 | 包 | 示例 |
|---|---|---|---|
| Filter | `{功能}Filter` | `filter/` | `CredentialAuthFilter` |
| Controller | `{资源}Controller` | `controller/` | `ModelController` |
| Service | `{资源}Service` | `service/` | `CredentialService` |
| Mapper | `{资源}Mapper` extends `BaseMapper<*Entity>` | `mapper/` | `AppCredentialMapper` |
| **Entity** | 表名 PascalCase + **`Entity` 后缀** | `domain/entity/` | `AppModelAuthEntity` |
| **入参 BO** | 语义 + **`RequestBO` 后缀**（前端传值给后端） | `domain/bo/` | `CreateModelRequestBO` |
| **出参 VO** | 语义 + **`VO` 后缀** | `domain/vo/` | `ModelVO` |
| Adapter | `{提供商}Adapter` | `adapter/` | `AnthropicAdapter` |
| 异常 | 网关内部用 `BusinessException(ErrorCode)`；行内标准异常 `BizException` 可用（`com.pab.ficc.cus.tool.exception`），两者均由 GlobalExceptionHandler 处理 | — | — |

### 1.2 方法命名

| 操作 | 前缀 | 示例 |
|---|---|---|
| 查询单条 | `findBy{字段}` | `findByAppId` |
| 查询列表 | `listBy{字段}` | `listByAppId` |
| 插入 / 更新 | `insert` / `update` | `update(AppInfoEntity app)` |
| 删除 | `deleteById`（逻辑删除，@TableLogic 生效） | `deleteById(Long id)` |
| 启用/禁用 | `enable` / `disable` | `enableApp(String appId)` |
| 缓存失效 | `evict{资源}Cache` | `evictCredentialCache(String key)` |

### 1.3 常量命名

- 全大写下划线分隔：`MAX_RETRY_COUNT`
- Filter order 常量定义在各自 Filter 类内
- **接口路径**：统一定义在 `common.UrlConstant`，Controller 引用常量，**禁止散落路径字面量**（见 §5.2）

### 1.4 数据库字段 → Java 字段映射

- 下划线转驼峰，启用 `map-underscore-to-camel-case: true` 自动转换
- 示例：`app_id` → `appId`，`create_time` → `createTime`，`is_del` → `isDel`
- 常规字段**无需** `@TableField`；例外：基础字段的自动填充标注 `@TableField(fill = FieldFill.INSERT / INSERT_UPDATE)`，`isDel` 标注 `@TableLogic(value="0", delval="1")`

## 2. Mapper 层规范（强制）

- 每张业务表一个 `@Mapper` 接口，继承 `BaseMapper<*Entity>`，放 `mapper/` 包
- 简单 CRUD 用 `BaseMapper` 方法；复杂查询在 Service 层构造 `LambdaQueryWrapper`
- **禁止**：XML Mapper、手写 RowMapper；审计等特殊批量/删除语句允许 `@Delete/@Select` 注解 SQL（现仅 `AuditLogMapper`）

```java
@Mapper
public interface AppMapper extends BaseMapper<AppInfoEntity> { }

// Service 中
Optional<AppInfoEntity> findByAppId(String appId) {
    return Optional.ofNullable(appMapper.selectOne(
        new LambdaQueryWrapper<AppInfoEntity>().eq(AppInfoEntity::getAppId, appId)));
}
```

### 2.1 Entity 注解规范

```java
@Data
@TableName("mg_app")
public class AppInfoEntity {
    @TableId(type = IdType.AUTO)
    private Long id;
    private String appId;                    // 自动映射 app_id
    // ===== 内部规范基础字段（7 张管理表强制，AuditLogEntity 除外）=====
    @TableField(fill = FieldFill.INSERT)          private String creater;
    @TableField(fill = FieldFill.INSERT)          private LocalDateTime createTime;
    @TableField(fill = FieldFill.INSERT_UPDATE)   private String updater;
    @TableField(fill = FieldFill.INSERT_UPDATE)   private LocalDateTime updateTime;
    @TableLogic(value = "0", delval = "1")
    @TableField(fill = FieldFill.INSERT)          private String isDel;
    @TableField(fill = FieldFill.INSERT)          private String createrUm;
    @TableField(fill = FieldFill.INSERT_UPDATE)   private String updaterUm;
}
```

- 填充逻辑统一在 `AuditFieldMetaObjectHandler`，**禁止在 Service 手动 set 基础字段**（业务语义字段如 `updatedBy` 除外）

## 3. Service 层规范（强制）

- Service 只调用 Mapper 和其他 Service，**禁止写 SQL**
- 缓存操作统一在 Service 层（经 `GatewayCacheManager`），禁止 Controller 直接操作缓存
- 业务校验失败抛 `BusinessException(ErrorCode)`

### 3.1 WebFlux 线程切换

```java
// Controller：DB 操作必须切 boundedElastic；统一返回行内 Result
public Mono<Result<AppVO>> detail(@RequestParam String appId) {
    return Mono.fromCallable(() -> AppVO.of(appService.findByAppId(appId)))
               .subscribeOn(Schedulers.boundedElastic())
               .map(Result::success);
}

// Filter：同样必须包裹
return Mono.fromCallable(() -> credentialService.findByHash(hash))
           .subscribeOn(Schedulers.boundedElastic())
           .flatMap(cred -> { ... });
```

## 4. Filter 层规范（强制）

### 4.1 错误响应格式

- Filter 拒绝请求必须返回 `application/json`，格式为**旧结构** `common.Result<Void>`（`code/message`，对外业务契约保持稳定）
- **禁止**返回纯文本/HTML

```java
private Mono<Void> reject(ServerWebExchange exchange, HttpStatus status, ErrorCode errorCode) {
    var response = exchange.getResponse();
    response.setStatusCode(status);
    response.getHeaders().setContentType(MediaType.APPLICATION_JSON);
    byte[] bytes = objectMapper.writeValueAsBytes(Result.fail(errorCode));  // Jackson，禁止 fastjson
    return response.writeWith(Mono.just(response.bufferFactory().wrap(bytes)));
}
```

### 4.2 请求体读取

- Filter 读取请求体后**必须**重建请求流（`exchange.mutate().request(mutated).build()`），防止后续 Filter 读不到

### 4.3 order 值

- 每个 Filter 的 order 在类顶部常量定义，实现 `Ordered`；值见 02 §3，不得更改

## 5. Controller 层规范（强制）

### 5.1 返回类型（行内标准）

- 所有 Controller 方法返回 `Mono<Result<T>>`，其中 `Result` 为**行内标准** `com.pab.ficc.cus.web.result.Result`（`resultCode/resultMessage/data`，成功码 `00000000`）
- 成功用 `Result.success(data)`；禁止返回裸 `T` 或 `ResponseEntity<T>`
- 入参用 `domain.bo` 下 `*RequestBO` + `@Valid`

### 5.2 路径规范

- **固定路径**，变量经 `@RequestParam` 或请求体传递，**禁止 `@PathVariable`**（RBAC 按固定路径绑定角色）
- 路径常量统一 `common.UrlConstant`：类级 `@RequestMapping(UrlConstant.ADMIN_MODELS)`，方法级 `@GetMapping(UrlConstant.DETAIL)`

| 资源 | 基础路径常量 |
|---|---|
| 模型 / 系统 / 凭证 / 授权 / 访问 / 配置 / 统计 / 审计 | `ADMIN_MODELS / ADMIN_APPS / ADMIN_CREDENTIALS / ADMIN_AUTH / ADMIN_ACCESS / ADMIN_CONFIG / ADMIN_STATS / ADMIN_AUDIT` |

### 5.3 HTTP 方法语义

| 操作 | 方法 | 示例 |
|---|---|---|
| 查询列表 / 单条 | GET / GET `+DETAIL?id=` | `GET /admin/models/detail?modelId=` |
| 创建 | POST | `POST /admin/models` |
| 全量更新 | PUT `+UPDATE`（body 含 id） | `PUT /admin/models/update` |
| 状态开关 | PATCH `+ENABLE/DISABLE` | `PATCH /admin/models/enable?modelId=` |
| 删除 | DELETE `+DELETE?id=` | `DELETE /admin/models/delete?modelId=` |

## 6. 异常处理规范（强制）

- 业务异常：`BusinessException(ErrorCode)` 或行内 `BizException(resultCode, resultMessage)`
- `GlobalExceptionHandler` 统一捕获转行内 Result；**不得在 Controller 中 try-catch**
- 新错误码只能追加到 `ErrorCode.java`，格式 `NAME(code, message)`；禁止硬编码状态码

---

## 7. 日志规范（强制）

| 场景 | 级别 |
|---|---|
| 正常业务流程 | DEBUG（生产关闭） |
| 业务拒绝（401/403/429） | INFO |
| 预期外异常 | WARN |
| 系统级错误 | ERROR |

- **禁止**打印完整 API Key/SK/密码（末 4 位可见）；业务日志必须带 MDC traceId
- 使用 `@Slf4j`；**禁止** `System.out.println`

---

## 8. 实体类规范（强制）

- Entity 仅允许 MyBatis Plus 注解（`@TableName/@TableId/@TableField/@TableLogic`）+ Lombok；**禁止 JPA 注解**（`@Entity/@Table/@Column`）
- 禁止在 Entity 中写业务逻辑
- 时间字段一律 `LocalDateTime`（禁止 `java.util.Date`）
- 基础字段模板见 §2.1，新增管理表实体必须包含
