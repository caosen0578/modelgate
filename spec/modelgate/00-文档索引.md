## 平台核心架构

```
┌─────────────────────────────────────────────────────────┐
│                      ModelGate 平台                          │
├────────────┬───────────────┬────────────┬───────────────┤
│  模型管理   │  接入系统管理  │  授权管理   │  访问控制      │
│  录入模型   │  注册业务系统  │  颁发凭证   │  IP 白名单     │
│  配置上游   │  管理负责人    │  模型授权   │  域名白名单    │
│  鉴权方式   │               │  QPS/配额  │               │
├────────────┴───────────────┴────────────┴───────────────┤
│                    流量网关（Spring Cloud Gateway）        │
│  Admin鉴权 → 凭证鉴权 → 访问控制 → 模型授权 → 限流 → 路由 │
├─────────────────────────────────────────────────────────┤
│        上游适配器：OpenAI / Azure / Anthropic / Custom    │
└─────────────────────────────────────────────────────────┘
```

## 过滤器链（改 order 需评估审计与鉴权顺序，见 05 §6）

```
[WebFilter 层] TraceWebFilter(HIGHEST) —— 作用于全部请求（含 /modelgate/**、静态资源）
                    ↓ 生成 traceId 写入 Reactor Context，自动同步进 MDC
[GlobalFilter 层] 仅作用于匹配路由的业务流量 /v1/**
TraceFilter(-200) → CredentialAuthFilter(-190) → AppAccessControlFilter(-180)
→ BodyParseFilter(-175) → ModelAuthFilter(-170) → QuotaFilter(-160)
→ ModelRouteFilter(-140) → CircuitBreakerFilter(-50) → 上游转发
      ↓
TraceFilter.doFinally: AuditService（内存队列 → 批量写 MySQL）
```

- **TraceFilter 必须是第一个**：审计写在它的 `doFinally`，排在鉴权之后会导致
  401/403/429 等**被拒请求完全不进审计**（GlobalFilter 链在拒绝处即中断）。

- **QuotaFilter**(-160)：QPS / 日调用量 / 月 Token 三层配额管控，Redis fail-open
- **BodyParseFilter**(-175)：缓存请求体字节，提取 model 字段写入 `mg.modelId` exchange attribute
- **AppAccessControlFilter**(-180)：支持 `ip|cidr|domain|domain_wildcard` 四种规则；K8s 内部服务推荐配 Pod CIDR
- **管理面 `/modelgate/**` 不在本链路内**：上述过滤器一律跳过管理接口（判断依据 `UrlConstant.MANAGE_PREFIX`）。
  原 `AdminAuthFilter`(-200) 已移除，管理接口的身份校验由**内网逐接口鉴权体系**承担，本进程不做任何校验。
