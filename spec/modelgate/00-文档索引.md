## 平台核心架构

```
┌─────────────────────────────────────────────────────────┐
│                      ModelGate 平台                          │
├──────────┬──────────┬──────────────┬──────────┬─────────┤
│ 模型管理  │ 服务管理  │ 接入系统管理  │ 授权管理  │ 访问控制 │
│ 录入模型  │ 录入服务  │ 注册业务系统  │ 颁发凭证  │ IP 白名单│
│ 配置上游  │ 配置上游  │ 管理负责人    │ 模型授权  │ 域名白名单│
│ 鉴权方式  │ 探测配置  │              │ 服务授权  │         │
├──────────┴──────────┴──────────────┴──────────┴─────────┤
│                流量网关（Spring Cloud Gateway）           │
│  /v1/**  凭证鉴权 → 访问控制 → 模型授权 → 配额 → 模型路由 │
│  /svc/** 凭证鉴权 → 访问控制 → 服务授权 → 配额 → 服务路由 │
│          （两条链路**共用**凭证与访问控制，授权表各自独立） │
├─────────────────────────────────────────────────────────┤
│  模型上游适配器：OpenAI / Azure / Anthropic / Custom      │
│  服务上游：原样透传，只换凭证与地址（不解析请求体）        │
└─────────────────────────────────────────────────────────┘
```

## 过滤器链（改 order 需评估审计与鉴权顺序，见 05 §6）

```
[WebFilter 层] TraceWebFilter(HIGHEST) —— 作用于全部请求（含 /modelgate/**、静态资源）
                    ↓ 生成 traceId 写入 Reactor Context，自动同步进 MDC
[GlobalFilter 层] 作用于匹配路由的业务流量 /v1/** 与 /svc/**
TraceFilter(-200)  ← 在这里算一次 TrafficType 存 attribute，后续 8 个过滤器只读不算
→ CredentialAuthFilter(-190) → AppAccessControlFilter(-180)          两类流量共用
→ ┌ 模型: BodyParseFilter(-175) → ModelAuthFilter(-170)
  └ 服务: ServiceAuthFilter(-170)                                     同 order，互斥
→ QuotaFilter(-160) → PayloadCaptureFilter(-145)                      两类流量共用
→ ┌ 模型: ModelRouteFilter(-140)
  └ 服务: ServiceRouteFilter(-140)                                    同 order，互斥
→ CircuitBreakerFilter(-50) → 上游转发
      ↓
TraceFilter.doFinally: AuditService（内存队列 → 批量写 MySQL）
```

- **流量分流一律用 `TrafficType`**，禁止在过滤器里写路径字面量或 `startsWith`（见 05 §6.1）。
  其兜底取值 `UNKNOWN` **必须算业务流量**（fail-closed）——路由谓词 `Path=/v1/**`
  的接受集比 `startsWith("/v1/")` 宽（`/v1`、`/v1;a=b/...`），判成内部流量会跳过全部鉴权。

- **TraceFilter 必须是第一个**：审计写在它的 `doFinally`，排在鉴权之后会导致
  401/403/429 等**被拒请求完全不进审计**（GlobalFilter 链在拒绝处即中断）。

- **QuotaFilter**(-160)：QPS / 日调用量 / 月 Token 三层配额管控，Redis fail-open
- **BodyParseFilter**(-175)：缓存请求体字节，提取 model 字段写入 `mg.modelId` exchange attribute
- **AppAccessControlFilter**(-180)：支持 `ip|cidr|domain|domain_wildcard` 四种规则；K8s 内部服务推荐配 Pod CIDR
- **ServiceRouteFilter**(-140)：**不读 body、不改写请求体、不碰 Content-Length**，原样流式透传 ——
  这是服务链路比模型链路轻一个量级的全部原因（模型链路必须把 body 读全才能拿到路由键 `model`）
- **管理面 `/modelgate/**` 不在本链路内**：上述过滤器一律跳过管理接口（判断依据 `TrafficType.INTERNAL`）。
  原 `AdminAuthFilter`(-200) 已移除，管理接口的身份校验由**内网逐接口鉴权体系**承担，本进程不做任何校验。
