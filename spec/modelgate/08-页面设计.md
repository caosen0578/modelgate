## P2 模型管理 `/models`

**列表页**

| 列 | 说明 |
|---|---|
| 模型 ID | 网关对外暴露的路由标识，带复制按钮 |
| 名称 | 展示名 |
| 提供商 | 带图标 |
| 类型 | Chat / Embedding 等 |
| API 规范 | openai / anthropic 等 |
| 状态 | 启用/禁用/维护中，带颜色标签 |
| 今日调用 | 当日请求数 |
| 操作 | 编辑 \| 测试连通 \| 启用禁用 \| 删除 |

**新增/编辑弹窗（分步表单，共 3 步）**

```
步骤 1：基础信息
  - 模型 ID（网关对外 ID，新增/编辑均可修改；改名需二次确认）
  - 上游真实模型 ID（供应商原始 ID；留空表示与模型 ID 相同）
  - 名称、提供商（选择后自动填充默认上游地址）
  - 模型类型、描述

步骤 2：连接配置
  - 上游地址
  - API 规范（选择后显示对应的说明文字）
  - 鉴权类型 + 对应的密钥输入框
    api_key   → [API Key 输入框]
    ak_sk     → [Access Key] + [Secret Key]
    azure     → [API Key] + [Resource Name] + [Deployment ID] + [API Version]
    none      → 无需配置
  - 超时时间

步骤 3：参数配置
  - 默认参数（JSON 编辑器，带格式校验）
  - 强制参数（JSON 编辑器）
  - 自定义映射（api_spec=custom 时展示，JSON 编辑器）
  
  [测试连通] 按钮 → 显示测试结果（延迟、响应预览）
```

**🧪 模型测试工具**

- 下拉框选择的是网关对外 `modelId`，页面同时明确展示实际发送的 `upstreamModelId`。
- 原始测试请求体中的 `model` 使用上游真实 ID；额外参数中的同名字段不得覆盖它，服务端还须按库中配置二次校正。
- 快速连通性测试、保存前草稿测试和对话测试都验证真实上游 ID，并应用默认参数、强制参数与字段映射。
- 管理面测试跳过接入系统鉴权/授权/配额，只验证模型层配置；该说明必须在页面保留。

## P4 接入系统详情 `/apps/:id`

**子页签布局：**

```
[系统信息] [凭证管理] [模型授权] [访问控制]
```

### 子页签 1：系统信息
系统名称、系统编码、应用名称、应用 appId、应用编码等基础字段展示 + 编辑入口。
系统名称与应用名称是两个独立字段，新增和编辑时均展示；应用 appId 创建后不可修改。

### 子页签 2：凭证管理

```
[+ 生成新凭证] 按钮

表格：
凭证名称 | 类型    | 凭证值（末 4 位 + ****）| 状态  | 过期时间 | 操作
生产密钥  | API Key | ****...xyz4              | 启用  | 永久     | 📋 接入示例 | 🔑 查看密钥 | 禁用 | 删除
测试密钥  | AK/SK   | AK: abc*** SK: ****      | 启用  | 2027-01  | 📋 接入示例 | 🔑 查看密钥 | 禁用 | 删除
```

**📋 接入示例弹窗**（给接入方直接复制的调用报文）：
```
调用模型：[下拉：只列已授权+启用+未过期的模型]   网关地址：[http://host:port]
[ ] 流式返回（SSE）

⚠️ 示例中的密钥默认是占位符，避免误发到公共渠道。   [🔑 填入真实密钥]

[curl] [HTTP 原文] [Python]
┌──────────────────────────────────────────────┐
│ curl -X POST "http://host:port/v1/chat/...   │
│   -H "Authorization: Bearer <在此填入 API Key>│
│   -d '{"model":"gpt-4o","messages":[...]}'   │
└──────────────────────────────────────────────┘
提示：model 必须与「模型管理」录入的 model_id 完全一致…
[关闭] [复制示例]
```

- 密钥**默认占位符**，点「填入真实密钥」才走 `GET /modelgate/credentials/secret` 取回；
  关窗即从 DOM 清除。存量凭证（`secretRetrievable=false`）该按钮置灰。
- `ak_sk` 类型**不给静态报文**：签名与时间戳绑定（±5min），写死必然 401，
  改为给出能现算签名的 bash / Python 脚本。
- 示例路径随模型类型切换：`chat`→`/v1/chat/completions`，`embedding`→`/v1/embeddings`；
  `image`/`audio` 明确提示需按上游实际接口调整，不假装能直接跑。

**生成凭证弹窗：**
```
凭证名称：[         ]
凭证类型：○ API Key  ○ AK/SK
过期时间：[日期选择] （可选，空=永久）
备    注：[         ]
[确认生成]

⚠️ 生成后 Secret Key 仅显示一次，请妥善保存！
```

**生成成功弹窗（含一键复制）：**
```
✅ 凭证生成成功

API Key：ModelGate-crm-service-sk_live_abc123xyz456
         [一键复制]

⚠️ 此凭证只显示一次，关闭后无法再次查看
[我已复制，关闭]
```

## P6 系统配置 `/settings`

```
网关全局配置（存 gateway_config 表，实时生效）：

┌────────────────────────────────────────────────┐
│ 鉴权总开关          [● 开启]                    │
│ 熔断开关            [● 开启]                    │
│ 默认限流（全局QPS）  [100] 次/秒                 │
│ AK/SK 时间窗口      [300] 秒（防重放）           │
└────────────────────────────────────────────────┘
```

> **管理后台准入不在本页面维护，也不在本进程内实现。** 原「Admin 访问配置」卡片与
> `AdminAuthFilter` / `modelgate.admin.*` 均已移除。内网部署后由行内 4A 承担登录鉴权、
> 由内部角色权限体系承担逐接口鉴权与页面/按钮级控制。
>
> 侧栏底部的 ADMIN TOKEN 输入框、「连接 / 刷新」按钮、连接状态指示灯均已**移除**：
> 页面不再持有任何管理凭据，浏览器带的是内网鉴权层自己的会话（Cookie / 4A 票据）。
> 请求头只保留 `Content-Type`，**禁止**在前端再引入任何自管理的令牌输入。
> 页面切换即加载对应数据，不再有"先连接后使用"这一步。

## P7 报文记录 `/payload`

- 筛选区提供「请求报文 / 请求头」范围选择和一个全模糊关键字输入框；一次只激活一种检索，
  防止同一条 SQL 重复扫描两个大字段。
- 模糊检索必须搭配 ≥8 位 TraceID 或两端齐全且跨度 ≤24 小时的时间范围；请求头关键字至少3字符。
- 页面从 `/modelgate/payload/meta` 回显请求头单值/总字符上限，并明确提示“全部请求头留档，包含凭证”。
- 列表增加请求头 JSON 预览；详情弹窗增加「请求头」Tab，与请求报文、响应正文、响应原文分开渲染。
  请求头 Tab 展示全部入站 Header，包括 Authorization/Cookie/API Key/Token/JWT/签名等凭证字段。
- 请求头列表列固定为 140px 短预览，完整值通过悬浮提示或详情页查看，避免挤压请求报文和响应正文。
- 报文详情的「响应正文」在 assistant 文本下方展示从 `responseRaw` 解析出的工具调用；支持 OpenAI SSE
  `delta.tool_calls` 分片合并与 Anthropic `tool_use/input_json_delta`。纯工具调用、正文为空时仍能看到参数。
- 工具调用只在用户打开「响应正文」时由管理页懒解析并缓存；不新增数据库字段，不进入转发热路径。
