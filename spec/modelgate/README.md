## 平台核心架构

```
┌─────────────────────────────────────────────────────────┐
│                      ModelGate 平台                          │
├────────────┬───────────────┬────────────┬───────────────┤
│  模型管理   │  接入系统管理  │  授权管理   │  访问控制      │
│  录入模型   │  注册业务系统  │  颁发凭证   │  IP 白名单     │
│  配置上游   │  管理负责人    │  模型授权   │  域名白名单    │
│  鉴权方式   │               │  QPS/配额  │               │
├────────────┴───────────────┴────────────┴───────────────┤
│                    流量网关（Spring Cloud Gateway）        │
│  Admin鉴权 → 凭证鉴权 → 访问控制 → 模型授权 → 限流 → 路由 │
├─────────────────────────────────────────────────────────┤
│        上游适配器：OpenAI / Azure / Anthropic / Custom    │
└─────────────────────────────────────────────────────────┘
```

## 过滤器链（order 不得修改）

```
AdminAuthFilter(-200) → CredentialAuthFilter(-190) → AppAccessControlFilter(-180)
→ ModelAuthFilter(-170) → RateLimitFilter(-160) → TraceFilter(-150)
→ ModelRouteFilter(-140) → CircuitBreakerFilter(-50) → 上游转发
                                                          ↓
                                                   doFinally: AuditService (Kafka)
```
