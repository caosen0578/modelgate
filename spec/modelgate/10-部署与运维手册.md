# Spec Me2AI · 10 · 部署与运维手册

> **文档性质**：DevOps 交付文档。环境资源、配置、启动、监控、上线检查清单与已知风险登记。

---

## 1. 环境资源清单（申请用）

| 资源 | 用途 | 申请要点 |
|---|---|---|
| **MySQL 8.0（生产 TDSQL）** | 模型/系统/凭证/授权/访问规则/审计日志 | 数据源经 Apollo `tdsql_datasource_config` 命名空间下发；连接池 Druid；审计表容量见 §8 |
| **Redis（内网 CacheProvider）** | 凭证 L2 缓存、QPS/日/月配额（Lua 滑动窗口） | 需支持 Lua（EVAL）；集群配置由 Apollo 下发 |
| **Apollo 2.3.0** | 全部生产配置热更新 | 申请 AppId + 命名空间（含 `tdsql_datasource_config`） |

**不需要**：Kafka（审计仅写 MySQL）、Consul（未接入注册中心）。

**网络**：网关需可访问全部上游模型地址（`mg_model.upstream_url`）；入口经 SLB（idle timeout 600s，网关 `response-timeout=570s` 先于其超时）。

## 2. 环境变量清单

| 变量 | 必填 | 默认值 | 说明 |
|---|---|---|---|
| `MODELGATE_CRYPTO_KEY` | **生产必填** | 空（加密功能不可用） | 32 字节 base64（`openssl rand -base64 32`）；用于上游 SK/AKSK 加密。**为空时创建凭证/AKSK 验签运行期报错** |
| `ADMIN_TOKEN_OPS` | **生产必填** | `mg-admin-change-me-in-prod` | Admin Token（Header `X-Admin-Token`）。**禁止使用默认值上线** |
| `ADMIN_USERNAME` / `ADMIN_PASSWORD` | **生产必填** | `admin` / `changeme` | 管理页 Basic Auth。**禁止使用默认值上线** |
| `MODEL_UPSTREAM_URL` | 否 | `http://127.0.0.1:9090` | Gateway 静态路由占位地址；真实转发目标由 ModelRouteFilter 按模型配置动态覆盖 |

以上均可由 Apollo 覆盖；本地开发用 `application.yml` fallback。

## 3. 构建与启动

```bash
mvn clean package        # JDK 17 + Maven；产物 target/modelgate-1.0.0-SNAPSHOT.jar
```

**推荐 JVM 参数**（依据 [09-压测方案](./09-压测方案.md)，按压测结果调整）：

```bash
java -Xms4g -Xmx4g -XX:MaxMetaspaceSize=256m \
     -XX:MaxDirectMemorySize=2g \
     -XX:+UseG1GC -XX:MaxGCPauseMillis=200 \
     -XX:+HeapDumpOnOutOfMemoryError -XX:HeapDumpPath=/data/dump \
     -XX:+ExitOnOutOfMemoryError \
     -XX:ActiveProcessorCount=<容器CPU核数> \
     -jar modelgate.jar
```

系统层：`ulimit -n 65535`。

**端口与探针（K8s）**：

| 项 | 值 |
|---|---|
| 服务端口 | 8080 |
| liveness / readiness | `GET /actuator/health`（无需鉴权） |
| 指标抓取 | `GET /actuator/prometheus`（**需 Admin 鉴权**，Prometheus 抓取需配置 `X-Admin-Token` 头） |
| 副本 | 无状态，可水平扩展；限流/配额状态在 Redis，多副本一致 |

## 5. 监控指标与告警建议

指标出口：`/actuator/prometheus`（Micrometer）。

### 5.1 自定义业务指标

| 指标 | 类型 | 告警建议 |
|---|---|---|
| `modelgate.audit.queue.size` | Gauge | > capacity×70% 持续 5min → 警告（DB 写入跟不上） |
| `modelgate.audit.queue.capacity` | Gauge | 面板算水位百分比 |
| `modelgate.audit.dropped.total` | Counter | 增量 > 0 → 严重（正在丢审计日志） |

### 5.2 框架指标（重点）

| 指标族 | 关注点 |
|---|---|
| `resilience4j_circuitbreaker_state` | 熔断器进入 OPEN → 警告（按 model_id 维度） |
| `reactor_netty_connection_provider_*` | `pending_connections` 持续 > 0 → 连接池饱和 |
| `jvm_memory_used_bytes`（heap/nonheap）| old gen 持续上涨 → 泄漏排查 |
| `jvm_gc_pause_seconds` | P99 > 200ms → GC 调优 |
| `jvm_threads_*` / `executor_*`（boundedElastic）| 排队增长 → DB 慢或缓存击穿 |
| `http_server_requests_seconds` | 4xx/5xx 比例、P95 |
| 进程 FD（node exporter） | 持续增长 → 连接泄漏 |

### 5.3 日志

- Logback（`logback-spring.xml`），业务日志带 MDC `traceId`；响应头 `X-Trace-Id` 可反查
- 关键 WARN：`[AuditService] Queue full`（丢审计）、`Batch insert failed`（DB 写失败）、`[AdminAuth] Invalid token`（暴力尝试）

## 6. 上线检查清单（投产前逐项打勾）

### 阻断项（不完成不得上线）

- [ ] **执行 DB 变更**：目标库已跑 V1（新库）或 V2（存量），抽查 `is_del='0'` 回填与 `uk_app_model` 含 `is_del`
- [ ] **替换默认凭证**：`ADMIN_TOKEN_OPS`、`ADMIN_USERNAME/PASSWORD` 均非默认值（默认值上线 = 管理面裸奔）
- [ ] **设置 `MODELGATE_CRYPTO_KEY`**（32 字节 base64），并验证创建 AKSK 凭证成功
- [ ] **`mvn clean package` 通过** + 冒烟：admin.html 全功能点检（增删改查/启停）+ `/v1/chat/completions` 直通一次（含 stream）
- [ ] **Apollo 各命名空间就绪**：`tdsql_datasource_config`、Redis 集群配置、modelgate 自定义项

### 高危项（强烈建议上线前完成）

- [ ] **X-Forwarded-For 伪造防护**：Admin IP 白名单当前信任请求头 XFF（[AdminAuthFilter.getClientIp](../../src/main/java/com/pab/ficc/ibp/modelgate/server/admin/AdminAuthFilter.java)）；需在 SLB/F5 层清洗 XFF，或改为仅信任已知代理
- [ ] **CORS 收紧**：`allowedOriginPatterns: "*"` + `allowCredentials: true` 作用于 `/admin/**`，存在 CSRF 面；将管理接口 origin 收紧到管理页域名
- [ ] **Swagger 关闭或保护**：`/swagger-ui`、`/v3/api-docs` 当前无鉴权放行；生产 `springdoc.api-docs.enabled=false`（Apollo 可控）
- [ ] **逻辑删除唯一键决策**：`mg_model.model_id` / `mg_app.app_id` 唯一键未纳入 `is_del`，删除后同名重建会 Duplicate key；`mg_gateway_config` 软删后 save 同 key 将主键冲突（建议该表改物理删除）——需拍板方案

### 建议项（可放首个迭代）

- [ ] AK/SK 签名纳入 path+bodyHash 或 nonce 去重（当前 ±5min 窗口内可重放）
- [ ] Prometheus 告警规则按 §5 配置；Grafana 面板导入
- [ ] 按 [09-压测方案](./09-压测方案.md) 完成准发压测并归档报告

## 7. 已知设计取舍（风险登记，运维需知）

| 项 | 行为 | 影响 |
|---|---|---|
| 审计内存队列 | 进程崩溃丢失未刷盘记录（≤20万条）；队列满丢弃新记录 | 审计弱一致，主链路优先 |
| Redis 故障 → 配额 | QuotaFilter **fail-open**（放行） | 限流失效窗口内上游裸奔 |
| Redis 故障 → 鉴权 | L1 命中放行；L1 miss **fail-close**（拒绝，不穿透 DB） | 部分新请求 503 |
| 凭证过期响应码 | 返回 **401**（`CREDENTIAL_EXPIRED`） | 客户端按 401 处理 |
| WebFlux MDC | 行内 Result 的 `requestId/logTraceId` 跨 reactor 线程可能为空 | 用响应头 `X-Trace-Id` 兜底 |
| `/v1` 错误响应 | Filter 短路错误用旧 `code/message` 结构；管理接口用行内 `resultCode/resultMessage` | 两套契约并存，前端已适配 |

## 8. 容量基线

- 设计基准：400 用户 ≈ 150 并发，连接池 500（扩到 800 用户时连接池改 800 并重估 JVM 堆）
- 审计存量：稳态 ≈ QPS × 86400 × 90（保留 90 天）；30 QPS ≈ 2.3 亿行，需评估分区或缩短 `retention-days`
- 单请求内存：BodyParseFilter 全量缓存请求体（≤10MB/请求），高并发大 body 场景按 09 文档压测确认
