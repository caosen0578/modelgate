## P2 模型管理 `/models`

**列表页**

| 列 | 说明 |
|---|---|
| 模型 ID | 对外暴露的标识，带复制按钮 |
| 名称 | 展示名 |
| 提供商 | 带图标 |
| 类型 | Chat / Embedding 等 |
| API 规范 | openai / anthropic 等 |
| 状态 | 启用/禁用/维护中，带颜色标签 |
| 今日调用 | 当日请求数 |
| 操作 | 编辑 \| 测试连通 \| 启用禁用 \| 删除 |

**新增/编辑弹窗（分步表单，共 3 步）**

```
步骤 1：基础信息
  - 模型 ID（新增可编辑，编辑不可改）
  - 名称、提供商（选择后自动填充默认上游地址）
  - 模型类型、描述

步骤 2：连接配置
  - 上游地址
  - API 规范（选择后显示对应的说明文字）
  - 鉴权类型 + 对应的密钥输入框
    api_key   → [API Key 输入框]
    ak_sk     → [Access Key] + [Secret Key]
    azure     → [API Key] + [Resource Name] + [Deployment ID] + [API Version]
    none      → 无需配置
  - 超时时间

步骤 3：参数配置
  - 默认参数（JSON 编辑器，带格式校验）
  - 强制参数（JSON 编辑器）
  - 自定义映射（api_spec=custom 时展示，JSON 编辑器）
  
  [测试连通] 按钮 → 显示测试结果（延迟、响应预览）
```

## P4 接入系统详情 `/apps/:id`

**子页签布局：**

```
[系统信息] [凭证管理] [模型授权] [访问控制]
```

### 子页签 1：系统信息
基础字段展示 + 编辑入口

### 子页签 2：凭证管理

```
[+ 生成新凭证] 按钮

表格：
凭证名称 | 类型    | 凭证值（末 4 位 + ****）| 状态  | 过期时间 | 操作
生产密钥  | API Key | ****...xyz4              | 启用  | 永久     | 禁用 | 删除
测试密钥  | AK/SK   | AK: abc*** SK: ****      | 启用  | 2027-01  | 禁用 | 删除
```

**生成凭证弹窗：**
```
凭证名称：[         ]
凭证类型：○ API Key  ○ AK/SK
过期时间：[日期选择] （可选，空=永久）
备    注：[         ]
[确认生成]

⚠️ 生成后 Secret Key 仅显示一次，请妥善保存！
```

**生成成功弹窗（含一键复制）：**
```
✅ 凭证生成成功

API Key：ModelGate-crm-service-sk_live_abc123xyz456
         [一键复制]

⚠️ 此凭证只显示一次，关闭后无法再次查看
[我已复制，关闭]
```

### 子页签 3：模型授权

```
[+ 授权新模型] 按钮

表格：
模型名称    | 模型 ID    | 授权状态 | QPS 限制 | 日调用限制 | 月 Token | 到期时间 | 操作
GPT-4o      | gpt-4o     | ✅ 启用  | 10/s     | 10,000     | 500万    | 永久     | 编辑 | 撤销
Claude 3.5  | claude-3-5 | ✅ 启用  | 5/s      | 不限       | 不限     | 2026-12  | 编辑 | 撤销
```

**授权配置弹窗：**
```
选择模型：[下拉，勾选多个]
QPS 限制：[  10  ] 次/秒（0=不限）
日调用量：[10000 ]（0=不限）
月 Token：[     0] 万（0=不限）
有效期至：[日期] （可选）
[确认授权]
```

访问控制状态：[● 已启用 / ○ 已禁用]  ← 全局开关

IP / CIDR 白名单               域名白名单
┌────────────────────────┐     ┌────────────────────────┐
│ [+ 添加 IP 或 CIDR]    │     │ [+ 添加域名]            │
│                        │     │                        │
│ 10.0.0.0/8    [删除]   │     │ *.internal.com  [删除] │
│ 192.168.1.100 [删除]   │     │ app.corp.com    [删除] │
